### Get the ROM image

**[Download](https://libreboot.org/download.html) from release**

If you're using a release ROM, please ensure that you've inserted extra firmware
required refer to the [guide](../install/ivy_has_common.md) for that (, failure
to adhere to this advice will result in a bricked machine)

- Intel ME (vendor blob)


**[Build](https://libreboot.org/docs/build/) from source**

For the older one:

	./mk -b coreboot hp_elitebook_2560p_8mb

For the newer one:

	./mk -b coreboot hp_elitebook_2570p_16mb


### Internal/Software Flashing

**Default Libreboot firmwares [updatable](../install/simplified-sw-flashing.md).**


### External/Hardware Flashing

**REMOVE all power sources like battery, charger and so on, before doing this.
This is to prevent short circuiting and power surges while flashing; although
the flash is socketed, hot-swapping is generally a bad practice and must be
avoided.**

The flash chip is located between the memory slots and the PCH, covered by the base enclosure. [More here](https://doc.coreboot.org/mainboard/hp/2560p.html#programming)

**Check the [hw-flashing guide](../install/simplified-hw-flashing.md) before moving onto the next step below.**

Flash it: (With rpi-pico as an example, edit the line if needed.)

	flashprog -p serprog:dev=/dev/ttyACM0,spispeed=16M -w filename.rom


### Set MAC address

This platform uses an Intel Flash Descriptor, and defines an Intel GbE NVM
region. As such, release/build ROMs will contain the same MAC address. To
change the MAC address, please read [nvmutil documentation](../install/nvmutil.md).
